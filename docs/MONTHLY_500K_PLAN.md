# 工場キャリア診断｜月50万円を狙う運営計画

## 目的
月50万円は保証値ではなく、SEO流入・内部回遊・広告クリック・広告主側CVR・承認率の積み上げで狙う目標とする。

## 収益の式
月間収益 = セッション × 収益記事到達率 × 広告クリック率 × 広告主側CVR × 承認率 × 平均承認報酬

報酬5万円なら承認10件、3万円なら約17件、2万円なら25件で50万円。報酬単価だけでなく承認率と成果地点を重視する。

### 作業用シナリオ（予測ではない）
10,000セッション × 収益記事到達35% × 広告CTR12% × 広告主CVR6% × 承認65% × 平均3万円 ≒ 49万円。

## 優先順位
1. 8本の収益中核記事を強くする
2. 周辺記事から8本へ内部リンクを集める
3. 「転職エージェント」「求人の見方」「職務経歴書」「面接」など行動直前キーワードを追加
4. 診断結果から記事・ASP案件へ個別ルーティング
5. 無料ツールで滞在・再訪・被リンクの理由を作る
6. Search Consoleで表示回数が出たページを毎週改善
7. ASPの発生・承認実績で案件順位を入れ替える

## 見るKPI
- Organic sessions
- 収益中核8記事への到達数
- 診断開始数 / 完了率
- 記事→ASPクリック率
- 診断結果→ASPクリック率
- ASP別 発生件数 / 承認率 / 承認報酬
- Search Console: query, impression, CTR, average position

## 変更ルール
- 300PV未満でCVR判断を急がない
- 報酬単価だけで案件順位を決めない
- 根拠のないランキング・口コミ・求人数を掲載しない
- ASPの成果条件・対象者・否認条件が変わったら即修正
- 薄い記事量産より、検索意図が異なる記事とツールを優先

## ASP優先の初期仮説
- 工場勤務を辞めたい: メーカーズジョブ → ZEN
- 夜勤がきつい: メーカーズジョブ → ZEN
- 製造業30代: メーカーズジョブ → Samurai Job
- 生産技術: メーカーズジョブ / Samurai Job（承認条件と実績で入替）
- 品質管理: メーカーズジョブ / Samurai Job（同上）
- 年収500万円: Samurai Job → メーカーズジョブ
- 製造業から異業種: マジキャリ → メーカーズジョブ
- 期間工のその後: メーカーズジョブ → マジキャリ

- 成果条件・否認条件のスクリーンショット
