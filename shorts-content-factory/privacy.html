プライバシーポリシー

最終更新日：2026年9月13日
Shorts Content Factory（以下「本ツール」）は、個人開発者が自身で管理するYouTubeチャンネルの運用支援に使用する内部用デスクトップツールです。本ツールはYouTube API Servicesを利用します。

1. 利用するサービス

本ツールは、Googleが提供するOAuth 2.0、YouTube Data API Services、および必要に応じてYouTube Analytics API Servicesを利用します。本ツールを利用する際には、YouTube Terms of ServiceおよびGoogle Privacy Policyも適用されます。

2. 取得・利用する情報

本ツールは、本人がGoogle OAuth 2.0で明示的に許可した範囲に限り、YouTubeチャンネル情報、動画情報、動画統計、コメント、アップロードや更新に必要な情報、YouTube Analyticsデータ等へアクセスする場合があります。また、YouTube Data APIを通じて公開動画のタイトル、チャンネル名、公開日時、再生回数、高評価数、コメント数等の公開情報を取得し、企画・トレンド研究に利用する場合があります。

本ツールはYouTubeまたはGoogleのユーザー名・パスワード等のログイン認証情報を取得、要求、保存しません。

3. 利用目的

  • 本人が管理するYouTubeチャンネルへの動画アップロード、サムネイル設定、タイトル・説明文等の更新
  • 公開日時・公開範囲等の管理
  • 本人のチャンネルに投稿されたコメントの確認および返信
  • 本人の動画・チャンネルのパフォーマンス分析
  • YouTube上の公開データを用いたテーマ・企画・コンテンツ改善の研究
  • 本ツールの安全性、誤投稿防止、動作確認、ログ記録

4. 保存場所と安全管理

OAuthトークン、設定情報、取得データは原則として本ツールを実行する本人のローカルPC上に保存します。APIキーやOAuthクライアントシークレットを公開リポジトリや第三者へ意図的に公開しません。保存データへの不正アクセスを防ぐため、OSのアクセス制御その他の合理的な安全措置を講じます。

5. 第三者提供

本ツールは、取得したYouTube APIデータや認可済みユーザーデータを販売しません。また、本人の許可なく第三者へ提供しません。YouTube API Servicesの利用に必要なGoogle/YouTubeとの通信、法令に基づく場合、または本人が明示的に許可した場合を除きます。

6. データの保存期間・更新

公開YouTubeデータなどのNon-Authorized Dataは、YouTube API Services Developer Policiesに従い、原則として30暦日を超えて同じ状態のまま保持せず、30日以内にAPIから更新するか削除します。認可済みデータについても、利用目的に必要な範囲で保持し、適用されるYouTube API Servicesのデータ保存ポリシーに従って定期的に認可状態・データ状態を確認します。

7. OAuthアクセスの取り消し

ユーザーはGoogleアカウントの権限管理画面から、いつでも本ツールのアクセス権を取り消すことができます：

Google アカウントのサードパーティアクセス管理

アクセスが取り消されたことを本ツールが確認した場合、当該認可に基づいて保存したデータをできる限り速やかに削除します。ユーザーが本ツール内の削除手段を利用して取り消した場合、認可トークンを速やかに無効化し、関連する認可済みデータを原則7暦日以内に削除します。Google側の権限管理から取り消された場合も、ポリシーに従い関連APIデータを削除します。

8. データ削除の請求

本ツールに保存されたユーザーデータの削除を希望する場合は、データ管理・削除ページに記載する方法で削除できます。削除要求を確認した場合、対象データをできる限り速やかに、遅くとも7暦日以内に削除します。本ツール側のデータ削除はYouTube上の元データを削除するものではありません。

9. Cookie・広告

この監査・情報ページ自体では、Shorts Content FactoryのOAuth認可やYouTube APIデータをブラウザに保存しません。本ページにShorts Content Factory独自の広告配信や行動追跡用Cookieを設置する目的はありません。

10. ポリシーの変更

YouTube API Servicesの仕様・ポリシーまたは本ツールの機能変更に応じて、本ポリシーを更新する場合があります。重要な変更がある場合は、この公開ページの内容を更新します。

11. お問い合わせ

本ツールは個人利用の内部ツールです。YouTube API Servicesの監査・コンプライアンスに関する連絡には、Google Cloud Consoleおよび監査申請で登録した連絡先を使用します。
