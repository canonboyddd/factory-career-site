Shorts Content
Factory

個人クリエイターが、自身で管理するYouTubeチャンネル向けに、Shorts動画の制作支援、アップロード、メタデータ管理、コメント対応、分析を行うための内部用デスクトップツールです。一般ユーザー向けの公開サービスではありません。

プライバシーポリシーデータ利用・削除方針

主な機能

APIクライアントは、作成者本人が所有・管理するYouTubeチャンネルに対してのみ使用します。第三者のYouTubeアカウントへ無断でアクセスする機能はありません。

動画制作・アップロード

Shorts動画、タイトル、説明文、タグ、サムネイルを作成し、本人が選択したYouTubeチャンネルへアップロードします。

予約・メタデータ管理

公開日時、公開範囲、タイトル、説明文などを管理します。YouTube上の操作は、本人が事前に許可した範囲でのみ実行します。

リサーチ

公開されているYouTube動画のメタデータや統計情報をYouTube Data API経由で取得し、テーマ研究や企画改善に利用します。

コメント対応

本人のチャンネルに投稿されたコメントを確認し、必要に応じて返信します。自動処理には上限と安全条件を設けます。

Analytics

本人がOAuthで許可した場合に限り、YouTube Analytics APIを使って視聴状況や動画パフォーマンスを分析します。

品質改善

自身の投稿結果と公開データを比較し、企画・構成・編集テンポ等の改善に活用します。YouTubeの画面スクレイピングは行いません。

YouTube APIの利用方法

Shorts Content Factoryは、YouTube Data API Services および、必要に応じて YouTube Analytics API Services を使用します。

1Google OAuthで本人が許可
2対象チャンネルを明示して固定
3本人の操作・設定に基づき処理
4API経由でアップロード・取得
5保存データを定期更新・削除
本ツールはYouTubeのログインIDやパスワードを収集・保存しません。Google OAuth 2.0で付与された認可情報のみを、ローカル環境で保護して利用します。

データとユーザーコントロール

対象取扱い
OAuthトークン本人のPC上で保存し、許可されたYouTube機能の実行にのみ利用します。
公開YouTubeデータYouTube APIから取得し、研究・比較のため一時保存します。ポリシーに従い30日以内に更新または削除します。
認可済みYouTubeデータ許可された目的の範囲でのみ利用し、認可状態を定期確認します。
アクセス取り消しGoogleアカウントのセキュリティ設定からいつでも取り消せます。詳細はデータ管理ページに記載しています。
