データ管理・削除

最終更新日：2026年9月13日
ユーザーは、本ツールに付与したYouTube APIアクセスをいつでも取り消し、本ツールに保存された関連データの削除を行うことができます。

1. Google側でアクセスを取り消す方法

Googleアカウントの「サードパーティ製アプリとサービスへの接続」からShorts Content Factoryのアクセスを取り消してください。

Googleのアクセス権管理を開く

取り消し後、本ツールは当該OAuthトークンを使用したYouTube APIアクセスを継続しません。本ツールが認可失効を確認した場合、関連するAPIデータをポリシーに従って削除します。

2. ローカル保存データを削除する方法

本ツールは原則として本人のWindows PC上にデータを保存します。利用停止時は、Shorts Content Factoryフォルダ内の認証トークンおよびAPI取得データを削除できます。

データ削除対象の例
OAuthトークンsecrets/tokens/ 内のチャンネル別トークン
Analytics・API取得データdata/ 内のYouTube API由来データ
競合研究データ公開YouTubeデータを保存した研究DB・レポート
ローカルログ実行ログ、投稿履歴、分析結果など

※ 実際の保存先は本ツールのバージョンにより異なる場合があります。削除前に必要な自作動画・素材・設定のバックアップを確認してください。

3. 削除期限

ユーザーが本ツール内の手段でアクセスを取り消した、または保存データの削除を求めた場合、関連する認可済みデータをできる限り速やかに、遅くとも7暦日以内に削除します。Googleの権限管理画面から認可が取り消されたことを検知した場合も、YouTube API Services Developer Policiesに従って関連データを削除します。

4. 30日ルール

公開動画のタイトル、チャンネル名、コメント本文等のNon-Authorized Data、または長期保存が個別に許可されていないAPIデータは、原則として30暦日以内にYouTube API Servicesから更新するか削除します。公開統計データについても、適用されるポリシーおよび監査で承認された範囲を超えて保持しません。

5. YouTube上のデータとの違い

本ツールのローカルデータを削除しても、YouTube上に存在する動画・コメント・チャンネル等の元データは自動的には削除されません。YouTube上のデータを削除する場合は、YouTubeまたは当該操作を明示的にサポートする認可済みAPIクライアントから操作してください。

6. 認可状態の確認

本ツールは保存済みOAuth認可が有効か定期的に確認し、無効化された認可に基づくアクセスを継続しないようにします。

7. 問い合わせ

監査・コンプライアンスまたはデータ削除に関する連絡には、Google Cloud ConsoleおよびYouTube API監査申請で登録した連絡先を使用します。
