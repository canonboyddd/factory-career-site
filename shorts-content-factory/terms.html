利用規約

最終更新日：2026年9月13日

1. 適用

本規約は、Shorts Content Factory（以下「本ツール」）の利用条件を定めるものです。本ツールは、開発者本人が自身で管理するYouTubeチャンネルの運用支援を目的とする内部用デスクトップツールです。

2. YouTubeの規約への同意

本ツールはYouTube API Servicesを利用します。本ツールを利用することにより、ユーザーはYouTube Terms of Serviceに拘束されることに同意するものとします。また、Googleによるデータの取扱いについてはGoogle Privacy Policyをご確認ください。

3. OAuth認可

本ツールは、ユーザーがGoogle OAuth 2.0を通じて明示的に許可した範囲でのみ、YouTube API Servicesへアクセスします。ユーザーは、Googleの同意画面で表示された権限を確認し、許可するかどうかを自ら決定できます。

4. YouTube上で実行する操作

本ツールは、ユーザーが設定・承認した範囲で、動画アップロード、サムネイル設定、タイトル・説明文等の更新、公開設定・予約管理、コメント確認・返信、分析データ取得等を行う場合があります。対象YouTubeチャンネルは認証時に識別し、誤投稿防止のためチャンネルIDを照合します。

動画の公開範囲や公開日時など、YouTube上のコンテンツ状態に関わる設定は、ユーザーが本ツールに与えた設定・指示に従って処理します。

5. 禁止事項

  • YouTube API Servicesの規約・ポリシーに違反する利用
  • 第三者のアカウントへの無断アクセス
  • APIキー、OAuthトークン、クライアントシークレット等の不正利用・共有
  • YouTubeまたはGoogleのログイン資格情報（ユーザー名・パスワード）の収集・保存
  • YouTubeサイトやアプリの無断スクレイピング
  • 権利侵害、スパム、欺瞞的行為、その他法令に違反する利用

6. データ利用

本ツールによるデータの取得、利用、保存、更新、削除についてはプライバシーポリシーおよびデータ管理・削除方針をご確認ください。

7. アクセスの取り消し

ユーザーはいつでもGoogleアカウントの権限管理画面から本ツールのアクセスを取り消すことができます。アクセス取り消し後のデータ処理についてはプライバシーポリシーに従います。

8. 免責

本ツールはYouTube上での再生数、収益、チャンネル成長その他の成果を保証しません。YouTube API Services、Googleサービス、外部サービスの仕様変更・停止等により、本ツールの全部または一部が利用できなくなる場合があります。

9. 規約の変更

本ツールの機能またはYouTube API Servicesの規約・ポリシー変更に応じて、本規約を更新する場合があります。変更後の内容は本ページで公開します。

10. 準拠

本ツールは、YouTube API Services Terms of Service、YouTube API Services Developer Policies、Google API Services User Data Policyその他適用される規約・法令を遵守することを前提に運用します。
