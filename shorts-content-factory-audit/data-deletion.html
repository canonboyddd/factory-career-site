Data deletion & revocation

アクセス取消し・データ削除

Google / YouTubeへのアクセス権を取り消し、本アプリに保存された関連データを削除するための手順です。

1. Revoke Google access

Googleアカウントの「サードパーティとの接続」から Shorts Content Factory を選び、「アクセス権を削除」を実行できます。

Open Google security permissions

Revoking access prevents the application from making future authorized YouTube API requests until authorization is granted again.

2. Delete locally stored data

本アプリは所有者本人のローカルPCで動作します。アクセス取消しまたは削除要求があった場合、以下の対象データを削除します。

Authentication data

  • OAuth access tokens
  • OAuth refresh tokens
  • Granted-scope / authorization cache associated with the revoked account

Authorized API data

  • Authorized channel analytics cache
  • Locally cached authorized channel/video metadata
  • Comment-management cache associated with the revoked authorization
Deletion is performed as soon as reasonably possible and, when required by YouTube API Services policies, no later than 7 calendar days after revocation or a valid deletion request.

3. What deletion does not do

本アプリのローカルデータを削除しても、YouTube上に存在する動画、コメント、チャンネル等のデータそのものは自動的には削除されません。YouTube側のコンテンツを削除する場合は、YouTubeまたはその操作を明示的にサポートする認証済みクライアントから実行する必要があります。

4. Contact for deletion requests

本APIクライアントは現在、所有者本人のみが使用する内部ツールです。削除・プライバシーに関する問い合わせは、YouTube API Compliance Audit申請でGoogle/YouTubeへ提出している運営者連絡先メールアドレスへご連絡ください。
