Shorts Content Factory

所有者本人が自分のYouTubeチャンネルを管理するための、Windowsローカル実行型の内部管理アプリケーションです。YouTube Data API、YouTube Analytics APIなどの公式YouTube API Servicesを利用し、動画のアップロード・予約公開・メタデータ管理・コメント運用・分析を行います。

Owner-operated local Windows application for managing the operator's own YouTube channels using documented YouTube API Services. This public page exists for transparency, privacy, and API compliance review.

Owner-operatedLocal Windows app5 owner-managed channelsNo public user accountsNo scraping

Application overview / 利用目的

本APIクライアントは一般ユーザー向けSaaSではなく、所有者本人のみが使用する内部管理ツールです。公開ページは審査担当者向けの説明・ポリシー掲示用であり、実際のAPIクライアントは所有者のPC上で動作します。

Internal / owner-operated

What the application does

  • Upload videos to the owner's YouTube channels
  • Set title, description, thumbnail and scheduled publication
  • Read channel/video statistics for an internal dashboard
  • Assist with comment review and replies on owner-managed channels
  • Research public video metadata through documented API endpoints
Public information page only

What this website is

This website is the public compliance information page for the application. It does not provide access to OAuth tokens, credentials, private dashboards, or channel-management functions.

Actual application access is limited to the owner on the owner's local Windows PC.

Core features / 主な機能

Video upload & scheduling

動画・タイトル・概要欄・公開設定・予約日時・サムネイルを管理し、YouTube Data APIを利用して所有者のチャンネルへ送信します。

Analytics dashboard

YouTube Analytics APIから取得した再生数、エンゲージドビュー、平均視聴率等を所有者専用のローカルダッシュボードに表示します。

Comment workflow

所有者のチャンネルに付いたコメントを確認し、必要に応じて返信などの管理操作を行います。操作対象は所有者が管理するチャンネルに限定されます。

Research & quality checks

公開動画のメタデータ取得には文書化されたYouTube APIエンドポイントを使用します。YouTubeウェブサイトのスクレイピングは行いません。内部の編集上の評価値はYouTube公式指標ではなく、内部ヒューリスティックとして扱います。

YouTube API Services usage

The application requests only scopes used by implemented features. Authentication is handled by Google's OAuth flow; the application does not request or store YouTube passwords.

Transparency & compliance

No credential collection

Google/YouTube login credentials are never collected by this application. Authorization occurs on Google's OAuth screens.

No sale of user data

Authorized YouTube data is used only to operate the owner's channel-management workflow and is not sold to advertisers or data brokers.

Local storage boundary

OAuth tokens, posting queues and analytics cache are stored on the owner's local PC for the application's operational purposes. They are not exposed on this public website.

Documented APIs only

The application is designed to access YouTube through documented YouTube API Services. It does not use hidden APIs or website scraping to obtain YouTube data.
