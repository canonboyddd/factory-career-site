利用規約

Shorts Content Factory の利用条件およびYouTube API Servicesとの関係を定めます。

Last updated: 2026-09-15

1. About the application

Shorts Content Factory（以下「本アプリ」）は、所有者本人が自分のYouTubeチャンネルを管理するためのローカルWindowsアプリケーションです。現時点では一般公開のSaaSとして提供していません。

2. YouTube Terms

本アプリを利用することで、利用者は YouTube Terms of Service に従うことに同意するものとします。

本アプリはYouTube API Servicesを使用しており、YouTube API Services Terms of ServiceおよびDeveloper Policiesに従うことを前提に運用されます。

3. Authorized actions

  • 動画のアップロード、予約公開、サムネイル・タイトル・概要欄等の管理
  • 所有者が管理するYouTubeチャンネルに関するコメント運用
  • 所有者のYouTube Analyticsデータの取得・表示
  • 文書化されたYouTube API Servicesを通じた公開メタデータの取得

本アプリが行う書き込み操作は、所有者が設定した運用ルールおよび承認済みのOAuth権限の範囲内でのみ実行されます。

4. User control

利用者は、本アプリに付与したGoogle/YouTubeアクセス権をGoogleアカウントの設定からいつでも取り消すことができます。アクセス取消し後のローカルデータの削除については、Data deletionをご確認ください。

5. Prohibited use

  • YouTubeまたはGoogleの認証情報を不正に取得・保存する行為
  • 未文書化API、スクレイピング等によるYouTubeデータ取得
  • 第三者のチャンネルへ無断で書き込み操作を行うこと
  • スパム、嫌がらせ、権利侵害、その他の不正利用
  • API credential、client secret、refresh token等の秘密情報の公開

6. Availability and changes

YouTube API Servicesの仕様変更、障害、割り当て、監査結果その他の要因により、本アプリの機能が変更または一時停止する場合があります。YouTube API Servicesの変更に応じて本アプリを更新します。

7. Privacy

本アプリにおけるデータの取扱いは、Privacy Policyに従います。
