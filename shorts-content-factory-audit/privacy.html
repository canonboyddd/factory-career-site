Privacy Policy

プライバシーポリシー

Shorts Content Factory におけるYouTube API ServicesおよびGoogle OAuth経由のデータ取扱いについて説明します。

Last updated: 2026-09-15

1. Scope / 適用範囲

Shorts Content Factory（以下「本アプリ」）は、所有者本人が自分のYouTubeチャンネルを管理するためのローカルWindowsアプリケーションです。現時点では一般ユーザー向けに提供していません。本ポリシーは、本アプリがYouTube API Servicesを利用してアクセス・取得・保存・利用するデータに適用されます。

本アプリは YouTube API Services を使用します。YouTube API Servicesの利用に関連して、Googleの Privacy Policy も適用されます。

2. Data accessed / アクセスするデータ

Authorized channel data

  • Authorized YouTube channel identifiers and basic channel information
  • Video metadata such as title, description, privacy status, publication schedule and thumbnail status
  • Comments and comment-management data needed for the owner's workflow
  • YouTube Analytics data such as views, engaged views, watch/retention-related metrics and other authorized channel statistics

OAuth authorization data

  • OAuth access and refresh tokens issued by Google
  • Granted scope information
  • Authorization status for each owner-managed channel

The application does not request, collect, store or process the owner's Google/YouTube password.

3. How data is used / 利用目的

Channel operations

動画のアップロード、タイトル・概要欄・サムネイル・公開設定・予約日時の管理、コメント運用など、所有者が明示的に設定したチャンネル管理目的にのみ使用します。

Analytics

取得したYouTube Analyticsデータは、所有者専用のローカルダッシュボード、投稿改善、品質確認に使用します。

Research

公開動画に関するAPIデータは、企画・編集傾向の研究のために使用します。内部で作成する評価値やスコアはYouTube提供の公式指標として表示しません。

Security / audit

チャンネルIDロック、OAuth状態の確認、投稿履歴・エラー確認など、本アプリの安全な運用および監査証跡のために使用します。

4. Storage and retention / 保存と保持

本アプリの認証トークン、投稿キュー、分析キャッシュ等は、所有者のローカルPC上に保存されます。この公開ウェブサイトにはOAuthトークン、client secret、API key、refresh token等の秘密情報を保存・公開しません。

  • OAuth tokens are retained only while needed for the authorized, owner-operated workflow.
  • Authorized analytics/statistical data may be retained for operational analysis while authorization remains active, subject to applicable YouTube API policies.
  • Other cached API data is refreshed or deleted within the time limits required by YouTube API Services policies.
  • Authorization validity is periodically rechecked as part of normal operation.

5. Sharing / 第三者提供

本アプリは、Authorized Dataを販売しません。また、広告業者、データブローカー、その他の第三者へ販売・貸与・提供する目的で使用しません。

APIリクエストおよびOAuth認証のためにGoogle / YouTubeと通信します。その他、法令上必要な場合を除き、Authorized Dataを外部第三者へ提供しません。

6. Cookies and device technologies

この公開情報ページは静的ページです。本アプリの認証トークンは公開サイトのブラウザCookieとして保存しません。実際のAPIクライアントは所有者のローカルPC上で動作します。

7. Revocation and deletion / 取消し・削除

Revoke Google access

Googleアカウントのセキュリティ設定から、いつでも本アプリのアクセス権を取り消すことができます。

Google third-party access settings

Delete locally stored data

アクセス取消しまたは削除要求があった場合、本アプリに保存されたAuthorized Dataはできるだけ速やかに、遅くとも適用されるYouTube APIポリシーで要求される期間内に削除します。

Data deletion procedure

8. Security / セキュリティ

秘密情報は公開ウェブページへ埋め込まず、ローカル環境で管理します。OAuth認証はGoogleの認証画面を使用し、本アプリはYouTubeのログイン認証情報を取得しません。

9. Contact / お問い合わせ

本APIクライアントは現在、所有者本人のみが利用する内部ツールです。プライバシー、データ削除、API利用に関する問い合わせは、YouTube API Compliance Audit申請時にGoogle/YouTubeへ提出している本アプリ運営者の連絡先メールアドレスへご連絡ください。監査担当者は、申請時の連絡先へそのまま返信できます。

If this API Client is later offered to additional users, a direct public contact method will be added before such access is provided.
